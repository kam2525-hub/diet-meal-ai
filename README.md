# MealAI (ミールAI) 🥗

> **「何を食べれば痩せるのか、考える面倒くささをゼロに。」**  
> コンビニ・外食チェーンで今すぐ買える商品から、1日の食事プランを自動提案・即座に調整してくれるダイエット食事秘書Webアプリです。

---

## 🌟 主な機能

1. **基礎代謝 (BMR) & 総消費カロリー (TDEE) 自動計算**
   - Mifflin-St Jeor式を採用し、年齢・性別・身長・体重・日常活動レベルから正確な消費カロリーを算出。
2. **月○kg減量からの1日目標カロリー自動逆算**
   - 脂肪1kg = 約7,200kcalとして計算。
   - 代謝低下や健康被害を防ぐ安全リミット（セーフティ機能）を標準搭載。
3. **PFCバランス（たんぱく質・脂質・炭水化物）リアルタイムゲージ**
   - 筋肉を落とさないよう、体重に合わせたタンパク質量（約90〜100g）の摂取進捗を可視化。
4. **わがまま・気分で即座に再計算（Cravingボタン）**
   - 🍰 **甘いもの食べたい**: 低糖質スイーツやSUNAOアイスを間食に組み込み、他でカロリーを自動調整。
   - 🧂 **しょっぱいものが欲しい**: スモーク豚タンやくきわかめなどを提案。
   - 🥩 **ガッツリ肉・外食**: 松屋やすき家などの高タンパク肉定食へ切り替え。
5. **前日やらかしリカバリーモード（🔄）**
   - 飲み会や食べすぎた翌日、ワンタップで目標を -300kcal 補正した相殺プランを生成。
6. **チートデイモード（🎉）**
   - メンテナンスカロリー以上まで枠を一時開放し、代謝を刺激。
7. **コンビニ・外食チェーン・ドリンク枠の指定**
   - セブン-イレブン、ローソン、ファミリーマート、松屋、すき家、大戸屋、吉野家、スターバックス等に対応。
8. **ワンタップ買い物メモ（📋）**
   - 今日の献立に必要な食材を「セブンで買うもの 3品」「松屋で頼むもの 1品」のように店舗別に自動集計。
   - レジ前で迷わずチェックできる買い物チェックリスト。

---

## 🚀 起動方法

### ローカル実行
```bash
# Windowsの場合
run.bat をダブルクリック

# または Python で実行
python server.py
```
ブラウザで `http://localhost:8085` が自動的に開きます。
